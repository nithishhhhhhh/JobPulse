# JobPulse

JobPulse is a simple app to keep track of job applications in one place.

## What it does

- Add and manage job applications
- Track status: Applied, Interviewing, Offer, Rejected
- Save recruiter details and interview dates
- Set follow-up dates
- Highlight overdue follow-ups
- Move applications using a Kanban board
- Save data in the browser using LocalStorage

## Why I built it

I wanted an easier way to track job applications without using multiple spreadsheets or notes.

## Tech Used

- Angular
- TypeScript
- HTML/CSS
- LocalStorage
